## Roadmap tracker

Roadmap tracker is a web app made for people like me who like to track their study path.

This first release is focused on my studies in Java and Spring Boot.

It has a pomodore timer because I like to track my time automatically instead of writing it down manyally.

You can manage your weekly and daily goals.

<img width="901" height="216" alt="image" src="https://github.com/user-attachments/assets/5f00637c-4a73-4bfa-8f18-e93ca0d4966a" />
